# Data Stock 📦📱 (Proyecto de Práctica Mobile)

¡Hola! Este es **Data Stock**, un proyecto personal que estoy desarrollando para poner en práctica mis conocimientos en el desarrollo de aplicaciones móviles. Mi objetivo con esta app es crear una herramienta visual y fácil de usar para controlar el stock de productos y gestionar inventarios.

Este repositorio me sirve como bitácora de aprendizaje mientras sigo estudiando y mejorando mis habilidades en el desarrollo Frontend y Mobile.

---

## 🎯 ¿Qué estoy practicando en este proyecto?

* **Creación de Interfaces (UI):** Diseñé desde cero las pantallas de inicio de sesión (Login) y de registro de usuarios, cuidando la parte visual.
* **Manejo de Estados con React:** Aprendiendo a controlar los campos de texto (`TextInput`) usando el hook `useState`.
* **Componentes Nativos:** Implementando vistas, botones y contenedores adaptables para celulares utilizando `StyleSheet`.

---

## 🛠️ Tecnologías que estoy usando

* **Base de la App:** React Native y JavaScript.
* **Entorno de Desarrollo:** Expo (SDK 54) para poder probar la app directamente en mi celular.
* **Estilos:** `StyleSheet` nativo para el diseño visual de los componentes.
